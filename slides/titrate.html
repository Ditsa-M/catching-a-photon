Testing redox control: titrate, freeze, measure, reverse

The protocol

Add a reductant (dithionite) in steps, measure the potential, freeze each sample to 77 K and record its emission. Then add an oxidant (ferricyanide).

Reading the result

A change that reverses with oxidant means redox control. A change that does not reverse means the protein was damaged.

Good practice

Measure E_h in the sample itself, add redox mediators so it equilibrates, and dark-adapt before freezing.

[21:23–22:13] How would you test this? Here's the experimental approach, shown as a schematic, not data. Add a reductant such as dithionite in steps, measure the potential in the sample, freeze each sample to 77 K and record its emission, focusing on the red band. Then add an oxidant such as ferricyanide. The reversal is the critical control: if the spectrum returns, the change came from redox state; if it doesn't, the protein was damaged. Good practice is to measure the potential in the sample itself, use redox mediators so the cofactors equilibrate with the solution, and dark-adapt before freezing so light doesn't set the redox state for you.
